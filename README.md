# Chemist AI Workflow

> 化学者のための AI エージェント活用法 — SPRING リカレント・リスキリング商品

## プロジェクト概要

電気通信大学 SPRING（戦略的研究人材育成事業）に採択された博士課程院生は、
リカレント・リスキリングに資するツールを各自開発・販売する義務がある。
本プロジェクトは、その成果物として**「化学者向け AI エージェント活用法」**を
構築・販売することを目的とする。

## ポジショニング

- **対象顧客**：化学・材料・実験系研究者（D 生・PD・若手 PI）
- **解決する課題**：
  1. 文献管理が散逸する／論文 DB を作りたいが手が回らない
  2. 計算化学（Gaussian/GROMACS など）の入力作成・結果解析を効率化したい
  3. 論文執筆プロセスで AI を「下書き屋」以上に活用したい
  4. 申請書・発表資料の品質を AI で底上げしたい
- **商品の核**：研究業務を **複数の "AI 部署" に分割し、ファイルベースで状態管理する** 方法論

## 設計方針：**CLI 中立 + Claude Code 最適**

| レイヤ | 中立性 | 内容 |
|--------|--------|------|
| **核：方法論** | OS / CLI 中立 | 部署設計、ファイル構造、運用ルール、品質ゲート |
| **実装 A：Claude Code 版（premium）** | Anthropic 専用 | Skills, Hooks, Sub-agents, MCP フル活用 |
| **実装 B：Codex CLI 版（basic）** | OpenAI 専用 | AGENTS.md ベースの簡易再現 |
| **実装 C：ChatGPT/Gemini Web 版（minimal）** | ブラウザのみ | 単一プロンプトに圧縮した最小版 |

→ 「Anthropic 依存リスク」を回避しつつ、Claude Code の優位性は前面に出す。
