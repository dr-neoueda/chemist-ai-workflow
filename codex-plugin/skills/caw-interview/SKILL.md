# caw-interview — 面接対策・模擬面接

就活モードの面接対策部スキル。想定問答づくりから模擬面接、振り返りまでを回す。

## いつ使うか

- `/caw-interview` を実行したとき
- 「面接対策」「模擬面接して」「想定質問を作って」「逆質問を準備して」「面接の振り返り」と言われたとき
- 面接の前（準備）・後（振り返り）

`office/`（就活モード）が無ければ `/caw` で就活トラックを促す。面接対策部が未作成なら作成を提案する。

## はじめてモードを尊重する

このスキルを実行する前に `office/AGENTS.md`（Claude Code では `CLAUDE.md`）を読み、冒頭に `> 運用モード: はじめて` があれば、`caw` skill の「はじめてモードの挙動」を全応答に適用する：**平易な日本語**で話し、専門用語（逆質問・深掘り・STAR 等）は初出で 1 行説明を添え、各ステップの最後に**「次はこれをしましょう」を 1 つ**だけ提示する。

## ワークフロー

### Step 0: モードを選ぶ

`AskUserQuestion` で 4 つから選ぶ：想定問答を作る / 模擬面接をする / 逆質問を準備する / 面接の振り返りを記録する。

### A. 想定問答を作る

- **必ず `work/companies/<企業名>.md`（`caw-research` の出力）を読み**、`work/self-analysis/`（強み・弱み・ガクチカ・`motivation.md` の志望動機/就活の軸）と合わせて定番質問の回答骨子を作る：自己紹介 / 志望動機 / ガクチカ / 強み・弱み / 学業・研究 / キャリアプラン / 逆質問。**`work/companies/<企業名>.md` が無ければ「先に `caw-research` で <企業> を調べましょう」と促す**（志望動機・企業理解の質が大きく変わるため）
- 回答は**棒読み暗記でなく要点を箇条書き**で持たせる（本番で言葉が出る形）
- `work/interview-prep/qa.md` に保存

### B. 模擬面接をする

- 面接官役として **1 問ずつ**質問する。ユーザーの回答に対し、**深掘りを 1〜2 問**（「それはなぜ？」「具体的には？」「一番大変だったのは？」）入れる
- 各回答に**改善フィードバック**を返す。観点: ① 結論先出しか ② 具体性（数字・行動） ③ 一貫性（自己分析・志望動機と矛盾しないか） ④ 長さ（30〜90 秒目安、長すぎ・短すぎ）
- 一通り終えたら総評（良かった点 + 次に直す点を各 1〜3 個）
- **傾向の学習（毎回・自分から確認）**：模擬面接で**繰り返し現れた弱点・効いた言い回し・よく出た質問**が今後にも効く汎用的なものなら、**ユーザーに言われる前に自分から**「次回以降の面接準備にも反映しますか？」と確認し、OK なら `work/interview-prep/_notes.md` に 1 行で蓄積する。**この挙動は Claude Code / Codex CLI / Gemini CLI で共通**。**その場限りの細かい指摘は記録しない**（聞きすぎない）。

### C. 逆質問を準備する

- **必ず `work/companies/<企業名>.md`（`caw-research` の出力）を踏まえ**、調べれば分かること（事業内容等）を避けた逆質問を 3〜5 個用意する（例: 入社後の成長・現場の働き方・評価のされ方）。無ければ `caw-research` を先に促す
- `work/interview-prep/<企業名>.md` に保存

### D. 面接後の振り返りを記録する

- `work/interview-prep/<企業名>.md` に「聞かれたこと・うまく言えたこと・詰まったこと・次への改善」を記録
- 詰まった質問は A の想定問答（`work/interview-prep/qa.md`）に反映し、**汎用的な傾向（繰り返す弱点・よく聞かれる質問・効いた言い回し）は確認のうえ `work/interview-prep/_notes.md` にも蓄積**して、企業を跨いで次の準備に引き継ぐ

## 面接の傾向ノート（`work/interview-prep/_notes.md`）

企業ごとの準備（`qa.md`・`<企業>.md`）とは別に、**模擬面接・振り返りから繰り返し見える傾向**（繰り返す弱点・よく聞かれる質問・自分に効いた言い回し）を、**確認のうえ** 1 行で蓄積する横断ノート。次の準備（A・B）で先に読み、同じ弱点を放置しない。使うほど面接準備が自分に最適化される（計算側 caw-playbook の Lessons Learned、執筆側 caw-write/caw-es の writing-preferences と同じ学習ループの面接版）。

- 記録は**汎用的な傾向のみ**。その場限りの細かい指摘は記録しない
- 追記前に「次回以降の準備にも反映しますか？」と確認（毎回・自分から）
- `office/` 設定は書き換えない

## 重要な注意事項

- 棒読み暗記を勧めない。要点保持型で、本番の深掘りに耐えられる準備にする
- 誇張・虚偽を勧めない。深掘りされて破綻する回答は作らない
- フィードバックは具体的に（「もっと良く」でなく「結論を最初の 1 文に」等）
- **企業固有の準備（想定問答・逆質問・志望動機）は `work/companies/<企業名>.md`（`caw-research` の出力）を必ず参照する**（絶対）。未作成なら `caw-research` を先に実行/提案する
- 成果物は `work/interview-prep/` に置く
- **模擬面接・振り返りの汎用的な傾向は、言われる前に自分から確認のうえ `work/interview-prep/_notes.md` に蓄積し、次の準備に引き継ぐ**（全 CLI 共通・その場限りの指摘は記録しない）
