# caw-write — 論文・申請書ジェネレータ

研究モードの執筆部スキル。論文・申請書・要旨などを、**本人の文体で・引用整合を保って**書く。就活の書類スキル `caw-es` の研究側の対応物。

## いつ使うか

- `/caw-write` を実行したとき
- 「論文を書いて」「Introduction を書いて」「Discussion を直して」「申請書を書いて」「学振の研究計画を書いて」「要旨を作って」「査読コメントへの返信」「カバーレター」と言われたとき
- 投稿先・申請区分・字数・セクションを渡されたとき
- 「私の文体で書いて」「文体を学習して」と言われたとき（→「文体プロファイル」 `work/manuscripts/_style/`）

`office/`（研究モード）が無ければ `/caw` で研究トラックのセットアップを促す。writing 部署が未作成なら作成を提案する。

## はじめてモードを尊重する

このスキルを実行する前に `office/AGENTS.md`（Claude Code では `CLAUDE.md`）を読み、冒頭に `> 運用モード: はじめて` があれば、`caw` skill の「はじめてモードの挙動」を全応答に適用する：**平易な日本語**で話し、専門用語（IMRaD・hedging・査読・科研費・自己評価 等）は初出で 1 行説明を添え、各ステップの最後に**「次はこれをしましょう」を 1 つ**だけ提示する。元に戻せない操作（上書き・外部送信）は必ず事前確認する。

## ワークフロー

### Step 1: 文書種別・要件を確認

次を確認する（不足は `AskUserQuestion` で聞く）：

- **文書種別**（下表）
- **言語**（論文＝英語を既定 / 申請書＝日本語を既定。ユーザーの明示があれば従う）
- **対象**（論文＝投稿先の誌名や分野 / 申請書＝制度名・区分〔学振 DC/PD・科研費・民間財団〕）
- **範囲**（フル / セクション単位 / 特定の設問・欄）
- **字数・語数制限**（あれば厳守。申請書は欄ごとに字数が違うことが多い）

| 種別 | 主なセクション・型 |
|---|---|
| **論文**（manuscript） | Title / Abstract / Introduction / Results / Discussion / Methods / Conclusion（IMRaD）。カバーレター・査読回答（response to reviewers）も含む |
| **申請書**（grant / fellowship） | 研究の背景・目的 / 学術的問い / 研究計画・方法 / 独自性・創造性 / 期待される成果 / 自己評価（研究遂行能力）。制度の様式に従う |
| **学会要旨**（abstract） | 背景 → 目的 → 方法 → 結果 → 結論 を字数内に圧縮 |
| **その他**（報告書・英文レター 等） | 結論先出し → 具体 → まとめ |

### Step 2: 素材を集める

- **`work/manuscripts/_style/`（文体プロファイル。`caw-intake` が自分の論文から抽出）があれば必ず読み、その文体（トーン・一文の長さ・hedging・構成の癖）で書く。** 無ければ統合 `inbox/` の自分の過去論文を直接読む。それも無ければ中立な学術文体で書き、「過去の自分の文章を `inbox/` に入れると文体を学べます」と一言添える。
- **`work/profile/`（`research-profile` / `key-findings` / `publications` / `methods` 等）があれば読む。** 申請書の「自己評価・研究遂行能力」や論文の自己引用・手法記述に使う。
- **引用は `work/papers/`（`caw-paper` が登録した文献要約 md）を一次ソースにする。** 各 md の frontmatter（著者・年・誌名・DOI）から本文引用＋文献リストを組み立てる。登録が無いテーマなら「先に `caw-research` で探して `caw-paper` で登録すると、その文献をそのまま引用できます」と促す（**実在しない引用を勝手に作らない**）。
- `work/topics/`（`caw-research` の文献リスト HTML）があれば背景のスコープ把握に使う。
- 素材が足りなければ `caw-intake`（自分資料の取り込み）や `caw-paper`（引用元の登録）を案内するか、最低限その場でヒアリングする。

### Step 3: 構成テンプレを選んでアウトライン

種別に応じた骨子を提示し、**ユーザーと合意してから本文に入る**（いきなり全文を書かない）。論文は IMRaD、申請書は制度様式、要旨は圧縮型。各セクションに「何を書くか」を 1 行で置いたアウトラインを先に作る。

### Step 4: 段階ドラフト（引用を挿入しながら）

- **アウトライン → セクション単位 → 全体**の順で書く。一度に全文を吐かず、セクションごとに提示して方向を確認できるようにする。
- **結論・主張先出し**を基本に、根拠（データ・引用）で支える。
- **引用は `work/papers/` の登録文献から**：本文引用（著者-年 or 番号、投稿先様式に合わせる）＋末尾の文献リストを生成。登録に無い主張は「**要出典**」と明示し、捏造しない。
- **字数・語数を必ずカウント**し、制限の範囲に収める（申請書は欄ごと）。生成後に字数を明示する（例:「Abstract 248 / 250 words」）。
- 物理量・化学用語は正確に（単位・汎関数名・化合物名の表記揺れを起こさない）。

### Step 5: 保存とチェック

- `work/manuscripts/<doc-slug>/` に保存（例 `work/manuscripts/adox-crystal-paper/`、`work/manuscripts/jsps-dc2/`）。**md 既定**。`.tex`/`.docx` は要望時（LaTeX 本文＋`references.bib`、または Word）。図は同フォルダか `work/figures/`。
- チェック: ① 字数オーバーが無いか ② 設問・投稿規程に答えているか ③ 引用が `work/papers/` と整合し、本文と文献リストが対応するか ④ 事実に反する誇張・未検証仮説の断定が無いか。
- **申請書の追加ガード**（メモリ feedback の一般則を内蔵）：
  - 他分野の審査員にも分かる**平易な日本語**（専門用語は初出で補足、略号の濫用を避ける）
  - **未検証の仮説を誇張しない**（「定量化する」等の断言を避け、「考察する／比較を試みる」など試行的表現を選ぶ）
  - **数値（応募総額・期間・字数・締切・実験値）は一次資料で確認**し、出典を添える
  - 引用は文中言及形式（`[n]` 番号の羅列を避ける）

### Step 6: 推敲ループ＋レビュー

- ユーザーの修正指示（「もっと簡潔に」「主張を弱めて」「200 字削って」「査読者 2 の指摘に答える形に」）で再生成。毎回字数を再カウントして提示する。
- **英文・引用整合のクロスチェック**：Claude Code 版は推敲後に `codex:review`（英文法・引用整合・主張の妥当性）を回す。Codex / Gemini 版は自己レビューで ①〜④ を再点検する。

## 文体プロファイル（`work/manuscripts/_style/`）

本人の過去論文から「書き方の癖」を抽出して再現する仕組み。**抽出本体は `caw-intake` が担当**（自分の論文 / CV / スライドから `work/manuscripts/_style/`・`work/profile/` を作る）。本スキルは執筆時に必ずそれを読んで踏襲する。文体プロファイルが無ければ `caw-intake` を案内するか、その場で過去論文を直接読む。**部署や `office/` の設定ファイル（`CLAUDE.md` / `AGENTS.md`）は書き換えない**（設定と文体を分離する）。

## 他スキルとの関係

- **`caw-intake` →（上流）** `work/manuscripts/_style/`（文体）・`work/profile/`（プロフィール）を供給。caw-write が消費する。
- **`caw-research` → `caw-paper` → `caw-write`**：探す → 登録 → 引用して書く。caw-write は `work/papers/` の登録文献を引用源にする。
- **`caw-slides` は兄弟（下流）**：成果を発表に。要旨を caw-write が書き、論文紹介・発表スライドを caw-slides が作る。
- **`caw-paper` と分離**：caw-paper＝他者の論文を読む / 登録、caw-write＝自分の論文を書く（就活の `caw-research`＝調べる / `caw-es`＝書く と同じ分け方）。

## 重要な注意事項

- **引用を捏造しない**。本文の引用は `work/papers/` 登録文献に裏付けのあるものだけにする。無ければ「要出典」と明示し、`caw-paper` での登録を促す
- **字数は絶対**。超過は必ず指摘し、収まるまで削る（テキストの字数の話なので誤魔化さない）
- **嘘・誇張・未検証仮説の断定を書かない**。データと文献の範囲で書く（特に申請書）
- **本人の文体を踏襲する**。`work/manuscripts/_style/` があれば必ず読む。生成後に文体の合致も確認する
- 成果物は **必ず `work/manuscripts/` 配下**（`office/` 配下に書かない）。既存ファイルは上書きせず、同名なら日付や `_v2` で分ける
- **本文・要約はユーザーの言語**で書く（論文は英語が既定でも、ユーザーが日本語を望めば日本語）
- **化学物理の用語・単位は正確に**（汎関数名・化合物名・単位の表記揺れを起こさない）
