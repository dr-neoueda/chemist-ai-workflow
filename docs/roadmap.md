## 当初計画からの逸脱（記録として残す）

立ち上げ時（2026-04-29）の計画は **「教材（テキスト商材）を書いて売る」** だった。
実際には **「4 CLI 対応プラグインを実装する」** 方向に転換し、`content/` `templates/`
`case-studies/` `marketing/` は作られていない。

**この転換は妥当だった**と考える理由：教材の章を読ませるより、スキルとして実装したほうが
価値の伝達が速く、テストユーザー会で実際に動かして検証できたため。
ただし副作用として **「売り物としてどう届けるか」（Phase 4）が丸ごと後回しになっている**。

### 商品モデル（2026-08-21 確定）

**売り物はプラグインではなく「導入伴走」。** プラグイン `caw` は無料の配布物として GitHub で公開し続け、
課金するのは**マンツーマンの導入伴走**（その人の研究に合わせて部署構成・Playbook・MCP まで初期化する）。
教材は**伴走した相手の復習用の付属物**で、単体では売らない。集合研修形式は採らない。

**なぜ伴走か**：テスト会 2 回で実地に判明した障壁（Gemini 無料枠の不足・git の隠れ前提・
初期構築のトークン過多）は、いずれも「配れば済む」ものではなかった。
SPRING のリカレント・リスキリング義務とも、教育・伴走の形が最も整合する。
