# 研究分野の規律

`office/CLAUDE.md`（Codex CLI では `office/AGENTS.md`）の「研究分野の規律」に入る規律。
オンボーディングの Call 1（分野・大分類）で決まる `field_group` を設定 JSON に書くと、
scaffold スクリプトが下の `### field = <群>` から 1 つを選んで差し込む。

- `field_group` が空なら **共通** を使う
- 下に無い値なら scaffold は何も書かずに止まる（綴りを直してやり直す）
- 群ごとに完結させる（共通の規律も各群に書く）。利用者が読むのは自分の群の 1 ブロックだけ

---

### field = 化学・材料

```markdown
- **物理量には必ず単位コメントを付ける**（例：`# kJ/mol`, `# Å`, `# fs`, `# K`）
- **計算パラメータは設定ファイルまたは引数で渡す**（ハードコーディング禁止）
- **乱数シードは固定**（再現性確保）
- **エネルギー単位変換に注意**（kcal/mol ↔ kJ/mol ↔ eV ↔ Hartree）
- **計算ソフトのバージョン依存挙動に注意**（GROMACS の mdp 文法など）
- **化学物理の用語は正確に**（汎関数名・基底関数・force field・cell parameter など）
```

### field = 物理・地球惑星

```markdown
- **物理量には必ず単位コメントを付ける**（例：`# eV`, `# T`, `# K`, `# m/s`）
- **計算パラメータは設定ファイルまたは引数で渡す**（ハードコーディング禁止）
- **乱数シードは固定**（再現性確保）
- **単位系を明記する**（SI・CGS・原子単位・自然単位系のどれかを決め、換算係数はコードに定数として書く）
- **測定値には不確かさを付ける**（統計誤差と系統誤差を分け、誤差の伝播を示す）
- **数値計算は収束を確かめる**（メッシュ・時間刻み・k 点・カットオフを変えても結果が動かないこと）
```

### field = 生命科学

```markdown
- **物理量・濃度には必ず単位を付ける**（例：`# µM`, `# mg/mL`, `# ×g`, `# °C`）
- **解析パラメータは設定ファイルまたは引数で渡す**（ハードコーディング禁止）
- **乱数シードは固定**（再現性確保）
- **遺伝子・タンパク質・生物種は正式表記で**（生物種ごとの命名規約に従い、UniProt・PDB・NCBI などの ID を併記）
- **生物学的反復と技術的反復を区別する**（n の数え方を明記し、多重比較は補正する）
- **倫理審査・遺伝子組換え・動物実験の承認番号は記録だけ**（可否の判断はユーザーと所属機関が行う）
```

### field = 工学・情報

```markdown
- **物理量には必ず単位コメントを付ける**（例：`# N`, `# Pa`, `# V`, `# Hz`）
- **計算パラメータは設定ファイルまたは引数で渡す**（ハードコーディング禁止）
- **乱数シードと実行環境を固定**（ライブラリのバージョンを記録して再現性を確保）
- **数値解析は収束と境界条件を確かめる**（メッシュ・時間刻みを変えても結果が動かないこと、境界条件を記録）
- **設計値・計算値・実測値を区別する**（表やグラフで混ぜない。公差・測定誤差を添える）
- **性能の比較は条件を揃える**（同じデータ分割・ハードウェア・評価指標で比べ、条件を併記）
```

### field = 共通

```markdown
- **物理量には必ず単位を付ける**（数値だけの列や変数を作らない）
- **計算・解析のパラメータは設定ファイルまたは引数で渡す**（ハードコーディング禁止）
- **乱数シードは固定**（再現性確保）
- **ソフト・ライブラリのバージョンを記録する**（結果の再現に必要）
- **分野の用語・固有名は正確に**（表記揺れを起こさない）
```
