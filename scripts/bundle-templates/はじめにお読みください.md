# caw をこの USB から導入する

**化学者のための AI エージェント導入伴走 — Chemist's AI Workflow (caw)**

このフォルダには caw の本体一式が入っています。GitHub からダウンロードできない環境でも、
このフォルダから導入できます。

---

## 先に確認してください（前提）

| 必要なもの | 確認方法 | 無いとき |
|---|---|---|
| **インターネット接続** | ふつうに Web が見られれば OK | **必須です。** caw は AI に問い合わせるので、ネット無しでは動きません |
| **AI CLI**（下記のどれか 1 つ） | ターミナルで `codex --version` | `npm install -g @openai/codex` |
| **Node.js**（LTS 版） | `node -v` | [nodejs.org](https://nodejs.org/) から LTS 版 |
| **Python 3** | `python3 --version`（Windows は `py --version`） | macOS は最初から入っています／Windows は Microsoft Store から |

> **git は不要です。** この USB から入れる場合、git は要りません。

対応している AI CLI:

| CLI | 状態 |
|---|---|
| **Codex CLI**（おすすめ） | ✅ 動作確認済み |
| **Claude Code** | ✅ 動作確認済み |
| GitHub Copilot CLI | ⚠️ 同梱していますが**実機確認がまだ**です |

## 導入手順

### macOS の場合

1. この USB の中身を、**デスクトップなど PC の中にフォルダごとコピー**してください
2. コピーしたフォルダでターミナルを開きます
3. 次を実行します

```bash
bash install.sh
```

### Windows の場合

1. この USB の中身を、**デスクトップなど PC の中にフォルダごとコピー**してください
2. コピーしたフォルダで PowerShell を開きます
3. 次を実行します

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1
```

あとは画面の指示に従ってください。使っている CLI を自動で見つけて導入します。

> **なぜ「PC の中にコピー」するのか**
> USB のパスを直接登録すると、**USB を抜いた時点で caw が動かなくなります**
> （ローカルフォルダを登録する方式では、その場所をずっと参照し続けるためです）。
> インストーラは自動で `~/caw-plugin`（Windows は `%USERPROFILE%\caw-plugin`）に
> コピーしてから登録するので、そのあとは USB を抜いて大丈夫です。

## 使ってみる

1. 研究プロジェクト用の**空のフォルダ**を作ります（例: `~/my-research`）
2. そのフォルダでターミナル（PowerShell）を開き、CLI を起動します

```bash
codex          # または claude
```

3. こう話しかけます

```
caw
```

研究分野や使っている計算ソフトなどをいくつか聞かれます。答えると、次の 2 つが自動で作られます。

```
my-research/
├── office/     ← AI の「部署」。秘書・文献・計算・執筆など 9 部署の運営情報
└── work/       ← あなたの成果物（論文 PDF・要約・スライド・解析結果）
```

以降は普通の日本語で頼めます。

| 頼み方の例 | 何が起きるか |
|---|---|
| 「今日の TODO を整理して」 | 秘書部が `office/secretary/todos/` に記録 |
| 「この PDF を登録して」 | 書誌情報つきの要約を `work/papers/md/` に作成 |
| 「ORCA でこの分子の構造最適化の入力を作って」 | 入力ファイルとジョブ記録を生成 |
| 「発表スライドを作って」 | 編集できる PowerPoint を `work/presentations/slides/` に生成 |
| 「環境を整えて」 | 足りない外部ツールを 1 つずつ理由つきで導入 |

## 困ったとき

| 症状 | 対処 |
|---|---|
| `install.sh` が「AI CLI が見つかりません」と言う | 先に CLI を入れてください（上の表）。入れたあともう一度実行 |
| Windows で「スクリプトの実行が無効」と出る | `powershell -ExecutionPolicy Bypass -File install.ps1` の形で実行してください |
| 導入後に caw が反応しない | CLI を一度終了して再起動してください |
| スライド生成でエラーが出る | CLI に「環境を整えて」と頼むと必要な Python パッケージを入れてくれます |
| 動きがおかしい | CLI に「caw-doctor」と頼むと構造を点検して直し方を教えてくれます |

## 更新するとき

新しい版の USB を受け取ったら、**同じ手順をもう一度実行するだけ**です。
古いものは `caw-plugin.old-<日時>` に自動で退避されます（消されません）。
